# Tea-Production
This was developed as my individual contribution for 
*ST3011 Statistical Programming, University of Colombo*

Tea Analytics is an interactive platform built to better understand tea production across Sri Lanka. The idea was to take data that can feel complex and present it in a way that is easy to follow.

It brings together information about different regions, elevations, and tea types, allowing users to explore how production changes over time and across locations.

What you can explore

• Production trends across different regions
• Differences between high, medium, and low-grown tea
• Basic insights into tea types and processing methods
• A clean and simple interface for easy navigation

This project focuses on making data more accessible and easier to understand for anyone interested in the Sri Lankan tea industry.
